## 二、横切质量维度

| 维度 | 评分 | 依据 |
|---|---|---|
| 类型安全 | 4/5 | strict 全开,零 as any/ts-ignore;但 tests 不进 typecheck、缺 noUncheckedIndexedAccess |
| 错误处理 | 4/5 | 服务器路径类型化错误全覆盖;客户端吞错 2 处 |
| 安全 | 4/5 | SSRF/RLS/令牌纪律好;日志泄漏令牌、local-credentials 无测试、单实例假设 |
| 性能 | 3/5 | 超时/QPS 覆盖全;routeCache 无界;无性能基准 |
| 可测试性 | 4/5 | 纯函数多、fixture 注入模式成熟;组件层与持久层是盲区 |
| 可观测性 | 3/5 | 结构化 JSON 日志 + providerStatus;无 metrics/trace/覆盖率报告 |
| 文档 | 3/5 | 架构文档好但计数漂移;2 篇过期文档未处置 |
| DX | 3/5 | 单命令 lint/test/build 齐全;无 dev-skill、无 benchmark harness |
