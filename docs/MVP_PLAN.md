# Voyage MVP Plan

## Must-run path

Create trip → AI generate → map → daily route → add place / food → reorder → recompute route → hotels / activities → tasks → budget → Today mode.

Out of scope: payments, tickets, real hotel checkout, real GPS.

## Priority

1. Trip Workspace
2. Map
3. Itinerary timeline
4. New Trip AI
5. Mobile Travel Mode
6. Explore
7. Hotel / Activity
8. Landing

If time is short, ship 1–5 at 9/10 rather than twenty pages at 5/10.

## Demo seed

Chongqing, 20–22 Sep 2026, 2 travelers, ¥2,500, food + night views, easy pace.

## Adapters

Product is complete with zero API keys (`MockMapProvider` + `MockTravelAgent` + `MemoryTripRepository`).
